# HOMIES block

Updated copy of the rva.guru/homies app. The original address is not changed.

This build keeps the original pieces and adds the friend-page layer:

- Photo upload for a custom Homie, resized on the phone.
- Idle bob, blink, and care hop using the original Tony, Betty, and Nori art.
- Shelf codes in the original `k` + 32 hex form. Copy the code, or copy a shelf pack to open the same custom Homies, portraits, pages, and messages on another phone.
- MySpace page, blurbs, claim codes, and messages for each Homie.

Hosted separately from rva.guru/homies.
